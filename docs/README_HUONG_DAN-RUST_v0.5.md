# Markdown Tabs v0.5.0 — Hướng dẫn nhanh

Đọc **`GHI-CHU-v0.5.0.md`** để biết đầy đủ những gì mới (ribbon, mặc định Xem trước, sửa lỗi trình bày/font/công thức, DOCX mở được trong Word, File → Gần đây, chức năng bổ sung).

## Cài đặt
1. Giải nén toàn bộ gói zip.
2. Nhấp đúp `Cai-dat-MarkdownTabs-Rust_v0.5.bat` (không cần admin, không cần Python).
3. Mở `Test-Rust_v0.5.md` để thử.

## Danh sách file
| File | Vai trò |
|---|---|
| `MarkdownTabs.exe` | Chương trình v0.5.0 (Windows 64-bit) |
| `Cai-dat-…_v0.5.bat/.ps1`, `Go-cai-dat-…_v0.5.bat/.ps1` | Cài đặt / gỡ cài |
| `GHI-CHU-v0.5.0.md` | Ghi chú phát hành, giới hạn, đề xuất |
| `Test-Rust_v0.5.md` + `Anh-test_v0.5.png` | Thử giao diện, công thức, xuất DOCX |
| `Test-Sua-loi_v0.5.md` | File cố tình lỗi để thử "Sửa lỗi trình bày & font" |
| `Test-Ma-cu-TCVN3_v0.5.md`, `Test-Ma-cu-VNI_v0.5.md` | File mã font cũ để thử chuyển sang Unicode |
| `Anh-chup-v0.5-*.png` | Ảnh chụp giao diện mới |
| `Bien-dich-Windows.bat` | Tự biên dịch trên Windows |
| `src-rust/` | Mã nguồn đầy đủ |
